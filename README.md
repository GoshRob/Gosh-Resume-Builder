# Gosh-Resume-Builder
Gosh Resume Builder is an AI-powered web application designed to help students, freshers, and job seekers create professional, ATS-friendly resumes tailored to their target job roles.A key feature of the system is its Skill Gap Analysis, which evaluates the user’s technical and soft skills against the requirements of a selected job role.
